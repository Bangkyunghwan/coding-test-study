# SWEA 1206 - View

**분류:** 완전탐색(브루트포스), 배열  
**시간 복잡도:** O(N)

## 풀이 접근

각 건물의 **양옆 두 개씩, 총 4개 건물**과 높이를 비교해야 한다고 생각했다. 주변 4개 중 현재 건물 이상으로 높은 건물이 있다면 조망권이 없으므로, **현재 건물을 제외한 4개 건물의 최댓값**을 구하면 된다.

- 현재 높이 > 주변 4개 건물의 최댓값 → 높이 차이만큼 조망권 확보
- 그 외 → 조망권 없음

## 시행착오

처음에는 최댓값을 구할 때 **현재 건물을 포함한 5개를 비교할지, 제외한 4개를 비교할지** 명확히 정하지 않았다. 그러다 보니 최댓값과 두 번째 최댓값을 모두 구해야 한다고 생각해서 코드를 복잡하게 작성했다.

이후 조망권을 계산하는 조건을 다시 보면서, **현재 건물을 제외한 주변 4개의 최댓값 하나만 있으면 충분하다**는 걸 깨달았고 풀이를 단순화했다.

## 배운 점

- 단순히 '주변 건물과 비교한다'에서 끝내지 말고, **정확히 어떤 값을 비교 대상으로 삼는지** 먼저 정의하자.
- 주변 네 건물의 최댓값은 `Math.max()`로 간결하게 구할 수 있다.
- SWEA에는 1206번처럼 **테스트케이스 개수가 10개로 고정**되어 있어 `T`를 입력받지 않는 문제도 있다. 기본 템플릿보다 문제의 입력 조건을 우선 확인하자.
- 모든 유효한 건물을 순회하는 **완전탐색**이다. 각 건물마다 주변 4개만 비교하므로 내부 반복문이 있어도 전체 시간 복잡도는 **O(N)**이다.

## 개선할 핵심 코드
주변 4개의 건물 높이를 비교할 때, 반복문 말고 Math.max를 이용한 코드

```java
for (int i = 2; i < count - 2; i++) {
    int max = Math.max(array[i - 2], array[i - 1]);
    max = Math.max(max, array[i + 1]);
    max = Math.max(max, array[i + 2]);

    if (array[i] > max) {
        solution += array[i] - max;
    }
}
```
