# SWEA 2072 - 홀수만 더하기

**분류** 구현, 조건문, 반복문  
**시간 복잡도** `O(T)` (`T`는 테스트 케이스 수)

## 풀이 접근

테스트 케이스마다 정수 10개 중 홀수만 더한다. `sum`을 0으로 시작하고, 숫자를 하나씩 읽으면서 `num % 2 != 0`이면 `sum`에 더했다. 10개를 다 읽은 뒤 `#1 23`처럼 `#케이스번호 합계` 형식으로 출력했다.

테스트 케이스마다 고정된 10개를 확인하므로 전체 시간은 `O(T)`다.

## 배운 점

이번 문제처럼 읽은 숫자를 바로 홀수인지 확인하고 합계에 더할 수 있으면 배열에 저장할 필요가 없다. `sum`은 바깥 반복문 안에서 0으로 초기화해서 이전 테스트 케이스의 합이 섞이지 않게 했다.
