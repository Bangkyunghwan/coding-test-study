# SWEA 1926 - 간단한 369게임

**분류** 구현, 문자열  
**시간 복잡도** `O(N log N)`

## 풀이 접근

1부터 `N`까지 반복하면서 각 숫자에 `3`, `6`, `9`가 몇 번 나오는지 확인하는 문제다. 자릿수를 하나씩 확인해야 해서 `String.valueOf(i)`로 정수를 문자열로 바꿨다. `charAt(j)`로 각 자리를 읽고 `'3'`, `'6'`, `'9'` 중 하나면 `count`를 1씩 올렸다.

`count`가 0이면 숫자를 그대로 출력하고, 1 이상이면 그 횟수만큼 `-`를 출력했다. 예를 들어 `20`은 `20`, `13`은 `-`, `33`은 `--`가 된다. 숫자 하나를 처리할 때마다 공백을 출력했다. 크게 막힌 부분 없이 문제 규칙을 그대로 구현했다.

## 시간 복잡도

바깥 반복문은 숫자 `N`개를 확인한다. 숫자 하나를 문자열로 바꾸고 검사하는 데는 그 숫자의 자릿수만큼 시간이 걸린다. `N`이 9에서 10, 99에서 100이 될 때마다 자릿수가 하나씩 늘어나므로 최대 자릿수는 `O(log N)`이다. 그래서 전체 시간 복잡도는 `O(N log N)`이다.

## 풀이 후 배운 점

### 정수를 문자열로 바꾸기

```java
String strNum = String.valueOf(i);
char firstDigit = strNum.charAt(0);
```

`String.valueOf(369)`는 `"369"`를 만든다. `charAt()`으로 꺼낸 각 자리는 `char`이므로 `3`을 확인할 때는 문자 리터럴 `'3'`과 비교한다.

### StringBuilder에 결과를 모아서 한 번에 출력하기

반복문에 들어가기 전에 `StringBuilder sb = new StringBuilder();`로 한 번 만들어 둔다. 반복문 안에서 `strNum`과 `count`를 구한 뒤, 각 숫자의 결과와 공백을 `append()`로 붙인다. `append()`를 호출할 때마다 같은 `StringBuilder`의 내용이 늘어난다.

```java
if (count == 0) {
    sb.append(strNum);
} else {
    for (int j = 0; j < count; j++) {
        sb.append('-');
    }
}
sb.append(' ');
```

반복문이 끝나면 `System.out.println(sb)`로 모아 둔 결과를 한 번에 출력한다. `println`이 내부에서 문자열로 변환해 주므로 `sb.toString()`을 직접 호출하지 않아도 된다. 결과를 `String` 변수에 담을 때는 `String result = sb.toString();`처럼 꺼내면 된다.

### % 10과 / 10으로 자릿수 확인하기

정수에 `% 10`을 하면 맨 오른쪽 자릿수를 얻고, 정수 나눗셈 `/ 10`을 하면 그 자릿수를 뗀 값이 남는다. 예를 들어 `369 % 10`은 `9`이고 `369 / 10`은 `36`이다. 같은 과정을 0이 될 때까지 반복하면 `9`, `6`, `3` 순서로 각 자리를 확인할 수 있다.

```java
int number = i;
int count = 0;

while (number > 0) {
    int digit = number % 10;
    if (digit == 3 || digit == 6 || digit == 9) {
        count++;
    }
    number /= 10;
}
```

이 문제에서는 `3`, `6`, `9`가 나온 횟수만 필요해서 오른쪽부터 확인해도 된다. `number`만 줄이면 원래 값 `i`를 유지할 수 있어서 `count`가 0일 때 `i`를 그대로 출력하면 된다.
